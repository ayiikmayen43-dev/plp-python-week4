# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## File Descriptions
- **welcome.py**: Defines a `welcome` function that accepts a name as a parameter and returns a personalized greeting string.
- **toolbox.py**: Contains utility functions for doubling numbers (`double`), checking passing grades (`is_pass`), and customizable greetings with default arguments (`greet`).

## Reflection
The hardest function to write was `greet` because it required understanding how default parameter values work when an optional argument is omitted versus provided.
